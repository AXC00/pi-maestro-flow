MCP tunnel auth mode determines where exact scope enforcement lives.

A profile-scoped exact action policy is enforceable only when the canonical OpenAI Secure profile's managed-forward issuer mints the gateway.tunnel credential. An ordinary gateway-auth profile delegates authority to the remote Agent's explicit Gateway pairing credential, so its profile cannot silently enforce a separate action list or workspace boundary. Treat gateway-auth profiles as empty ingress markers (or reject unsupported non-empty policy); never accept an allowlist that the selected provider does not enforce. Generic pairing must also canonicalize audience before rejecting gateway.tunnel, so whitespace cannot bypass the issuer boundary.
